# PoC-06: ダッシュボードの配布

- 優先: P1
- 決まること: [ADR-010](../decisions.md#adr-010-ダッシュボードとアラートの仕様)（配布の方法）
- 関連: [全体設計 7 章](../design/architecture.md#7-ダッシュボードとアラートの仕様)

## 目的

生成したダッシュボードとアラートを、3 種類の Grafana に配れるかを確かめます。

## 前提

- [共通の安全策](README.md#共通の安全策) を満たしています。
- PoC-05 で、両方のバックエンドで動くパネルが 1 つ以上できています。

## 手順

1. PoC-05 のパネルを使い、v1 の JSON を作ります。仮の生成スクリプトか、手書きで作ります。
2. 次の 3 つの環境に import します。
   - Grafana 13（ローカルのコンテナ）
   - Grafana Cloud
   - Amazon Managed Grafana 12.4
3. import 以外の配り方を確かめます。
   - ファイルによる provisioning
   - gcx
   - Git Sync（Grafana 13）
4. Grafana が管理するアラートのルールを、ファイルで配れるかを確かめます。
5. Amazon Managed Grafana では、サービスアカウントのトークンで API から配れるかを確かめます。

## 合格条件

- 3 つの環境すべてで、ダッシュボードが表示されること。
- 3 つの環境すべてで、アラートのルールが登録されること。
- 配り方ごとの可否の表が埋まること。

## 費用と後片付け

- 費用の目安: Amazon Managed Grafana は、利用者 1 人あたりの月額で課金されます（エディターで月 $9 前後の見込み。要確認）。この PoC で最も費用がかかる項目です。
- 後片付け: Amazon Managed Grafana のワークスペースを必ず消します。[チェックリスト](README.md#後片付けチェックリスト) もすべて確かめます。
