# PoC-09: コストの照合

- 優先: P1
- 決まること: [ADR-009](../decisions.md#adr-009-コストモデル)
- 関連: [全体設計 8 章](../design/architecture.md#8-コストモデル)、[MicroVMs の設計 9 章](../design/microvms.md#9-使用量の記録)

## 目的

MicroVMs のコストの推定が、実際の請求とどれだけ合うかを確かめます。

## 前提

- [共通の安全策](README.md#共通の安全策) を満たしています。
- 請求データ（CUR、Data Exports）を、PoC-04 の前に有効にしておきます。反映には最大で 24 時間かかります。
- PoC-04 の MicroVMs には、照合用のタグが付いています。

## 手順

1. PoC-04 で使った MicroVMs について、使用量の要約を集めます。RUNNING の秒数、バースト分、起動・再開・停止の回数を含めます。
2. 単価表で、推定の費用を計算します。
3. 翌日以降の CUR の明細と、項目ごとに比べます。項目は、計算、バースト、スナップショットの読み書き、保存です。
4. バースト分の測り方（コンテナの cgroup か、VM 全体の `/proc` か）を変えて、どちらが請求に近いかを比べます。
5. 再開のときにも、スナップショットの読み込み料金がかかるかを確かめます。
6. 東京リージョンの単価を、CUR から確かめます。

## 合格条件

- 項目ごとの差を、数値で記録できること。
- 総額の差が ±5% 以内であれば、ADR-009 を採用にします。v0.5 の合格条件も同じ値です。
- 差が大きい項目は、原因と直し方を ADR-009 に書きます。

## 費用と後片付け

- 費用の目安: PoC-04 の資源を使うため、追加の費用はほとんどありません。CUR の保存料は少額です。
- 後片付け: 照合が終わったら、CUR の出力先の S3 バケットを整理します。[チェックリスト](README.md#後片付けチェックリスト) もすべて確かめます。
